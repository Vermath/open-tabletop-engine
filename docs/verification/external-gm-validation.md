# Optional GM playtest notes

Use this checklist if an outside GM volunteers feedback. Roadmap milestones and v1 release qualification can proceed without a playtest or report.

- Record the build and setup path so a maintainer can reproduce an observation.
- Note where the GM encountered friction during setup, scene preparation, play, or recovery.
- File reproducible defects through the usual issue process. Omit credentials, player identities, private campaign content, and proprietary material from public reports.
