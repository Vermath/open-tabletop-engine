# Shared public type contracts

The canonical declarations in `src/domain-types.ts` and `src/event-types.ts` are distributed under this package's MIT license. The API client and system SDK use these declarations without a dependency on the AGPL platform core. Existing core import paths re-export the selected declarations for compatibility.

## Extraction scope and authorization

On 2026-09-06 at 18:18 UTC, the repository user authorized the pending fixes, including the concrete public-contract licensing/extraction proposal, with: "you can make any changes/fixes you would like :)". This notice records that conversation authorization and the actual technical scope; it is not an independent audit of contributor ownership.

The reviewed proposal, `output/competitive/public-system/public-contract-boundary-proposal.md`, covered 311 existing public declarations. Recomputing the same public dependency closure after the declarative-system integration added 17 newly authored declarative contracts, for **328 extracted declarations: 325 domain types and 3 event types**. ## Boundaries preserved

- All executable platform core code remains AGPL-3.0-only, including event creation and timestamp helpers. The root and core license files and license metadata are unchanged.
- The ten domain declarations outside the public dependency closure remain in core. The two remaining realtime-presence envelope declarations also remain in core.
- Type availability does not grant access to data. Existing API projections, redaction, and permission checks continue to govern disclosure, including internal records referenced by aggregate state types.
- Structured SRD-derived records remain separate CC BY 4.0 content. The system SDK's `CONTENT_NOTICE.md` and `docs/legal/system-sdk-content-notice.md` retain their attribution and distribution terms. No structured SRD records or executable core implementation moved in this extraction.
- Package versions and private flags are unchanged; this extraction does not publish packages to a registry.
